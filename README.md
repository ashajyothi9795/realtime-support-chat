# Real-Time Support Chat

A real-time full-stack chat application built using React, Node.js, Express, and Socket.IO.

## Features
- Real-time messaging
- Username system
- Typing indicator
- Online users count
- Auto-scroll chat
- Responsive UI

## Tech Stack
### Frontend
- React
- Vite
- Socket.IO Client

### Backend
- Node.js
- Express.js
- Socket.IO

## Installation

### Client
```bash
cd client
npm install
npm run dev

**#### Server**
